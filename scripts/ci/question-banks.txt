# scripts/ci/question-banks.txt — CI 题库清单（单一事实源）
#
# 格式：<目录名> <上游 URL>   （每行一条，# 开头为注释）
#
# 为什么单独成文件（cycle-62）：
#   ① CI cache key 用**本文件的哈希** → 改 CI workflow（注释/步骤顺序）不会让
#      1.9GB 题库缓存失效；只有**题库清单真的变了**才重新克隆；
#   ② 题库清单是「声明」，本文件是它的单一事实源 → 脚本与 CI 共用同一份，
#      不会出现「CI 克隆的仓与测试期待的仓不一致」。
#
# 选仓原则：覆盖断言真正需要的数据维度，同时把体积控制在 CI 可接受范围。

#   xingcezhenti  354MB  58,890 题（行测主力源）
