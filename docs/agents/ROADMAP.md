## 演进原则

1. **数据优先**：先把存量数据吃透（15 仓库里还有 gk-tuxing / qiuzhao-epi-bank 未充分利用），再谈新交互。
2. **离线优先**：规则引擎能做的绝不依赖模型；模型只做「锦上添花」（如 `ai_essay_review`）。
3. **不破坏纪律**：每加一个视图/端点，同步加断言 + 更新 docs/agents。
4. **沙箱先行**：任何宿主交互改动，先沙箱跑通再动主力。
