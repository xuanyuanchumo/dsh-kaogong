# 评审报告存放目录

> 每次开 PR 前的评审报告存到这里，命名：`YYYY-MM-DD-<主题>.md`
> 模板见 [../REVIEW.md](../REVIEW.md) §6

## 为什么报告要落盘

评审结论如果只存在于对话里，就无法被追溯——「上次为什么这么决定」在下一次改动时会重新变成争论。
本项目的既有传统是**事故簿落文件**（`INCIDENTS.md` R1–R28），评审报告是同一原则的延伸。

## 保留策略

- 报告**不删除**（历史靠 Git）
- 被后续报告取代时，在旧报告顶部加一行：`> 已由 <新报告文件名> 取代`
- 报告中的 minor 项必须同步登记到 [../BACKLOG.md](../BACKLOG.md)
