# 06 · 中介中心性、标签传播与并查集：从「图上的位置」到「学习路径枢纽」

> dsh-kaogong 研究文档 · cycle-19

## 1. 数学定义

**Brandes 中介中心性（Betweenness Centrality）**：节点 v 控制多少「最短路径」：

```
BC(v) = Σ_{s≠v≠t} σ_st(v) / σ_st
```

σ_st 为 s→t 最短路径数，σ_st(v) 为经过 v 的条数。Brandes 算法（2001）用**单源最短路 + 依赖累加**把 O(V³) 朴素算法降到 O(VE) 无权图（BFS 版）。

**标签传播（Label Propagation, Raghavan 2007）**：社区发现——每节点初始化唯一标签，迭代中取**邻居标签众数**（随机打平用确定性规则），直到收敛。O(E) 每轮，3-5 轮收敛，无需预设社区数。

**并查集（Union-Find）+ 路径压缩**：连通分量计数。`find` 沿父指针上溯并压缩路径，`union` 合并集合。均摊复杂度 O(α(N))——反阿克曼函数，实际可视为常数，是**理论最优与工程简单的双料冠军**。

**确定性纪律**：标签传播的「随机打平」用节点 id 序代替随机数——同输入两次输出深相等（smoke 断言）。**算法课上的 randomized tie-breaking 在可复现性要求下必须换成确定性规则**。

## 3. 中文思维：语言/学习场景启发

- **枢纽者，控往来也**：古代漕运的枢纽码头（如扬州）本身不是货源地，但所有航线经过它——中介中心性度量「谁被绕不开」。能力图上中介高的端点是「牵一发动全身」的修改风险点（graph_impact 的理论根据）。
- **物以类聚的自然聚类**：标签传播像「流言传圈」——消息在朋友圈内传得快，跨圈传得慢，几轮下来圈子自动浮现。学习内容自动聚成「言语/判断/数量」三大社区，用户无需手工归类。
- **连则并，断则分**：并查集的哲学是「关系的传递闭包」——A 认识 B、B 认识 C，则 A、C 同属一个圈子。连通分量=0 孤儿节点时白盒面板亮「孤儿告警」，孤儿=注册了但没人用的能力。

## 4. 工程实践价值

1. **top20 下发 + 本地补全**：服务端算概览、客户端算全量的分层计算——既控传输体积又保证渲染完整性。
2. **无递归并查集**：迭代版路径压缩防 V8 深栈溢出——递归在图算法里是定时炸弹。
3. **三种着色档共享同一分数归一管线**：min-max 归一 → 五停渐变 → 节点着色，新档位（如 closeness）只需接入分数管线，渲染零改动——**策略模式的函数式表达**。
