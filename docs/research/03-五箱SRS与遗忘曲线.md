# 03 · 五箱 SRS 与遗忘曲线：从「间隔重复」到「错题回炉调度」

> dsh-kaogong 研究文档 · cycle-19

## 1. 数学定义

间隔重复（Spaced Repetition）的心理学基础是 Ebbinghaus 遗忘曲线：记忆保持率随时间指数衰减 `R(t) = e^(-t/S)`，S 为记忆强度。每次成功回忆使 S 增长（经典 SM-2 用 `EF := EF + 0.1 - (5-q)(0.08+(5-q)*0.02)`），复习间隔按 `S` 的比例拉长。

本插件采用**简化五箱模型**（SM-2 的工程化降维）：

```
box ∈ [1,5]           — 箱位即间隔档：1→当天 · 2→隔天 · 3→3天 · 4→7天 · 5→半月
答错: box := max(1, box-1), consecutive := 0
答对: box := min(5, box+1), consecutive += 1
mastered ⇔ box ≥ 3 ∧ consecutive ≥ 2
调度: 未掌握者按 lastAt 最久先回炉（FIFO 贪心）
```

无错题时的**弱点加权抽题**：`weight(m) = 1/(rate(m) + 0.15)` —— 正确率低的模块权重大，0.15 平滑项防止 0% 模块权重爆炸（倒数函数在零点的奇异性用平滑项消除，这是数值稳定性常识）。

## 2. 本插件代码落地

| 落点 | 内容 |
|---|---|
| `src/server/srs.ts` | `recordWrong/recordRight` 箱位迁移；`sig = sha1(module|stem前120字)` 去重；容量 300 环形（先淘汰已掌握再淘汰最旧）；`/api/questions?sort=srs` 调度 |
| `src/server/http.ts` | `/api/check` 答错自动入错题本、答对且带 `fromWrongBook` 升箱 |
| `src/client/study-view.ts` | 错题本 UI 箱位徽章渲染 |

**容量治理**：300 环形上限 + 「先淘汰已掌握」淘汰序——已掌握的题占着位置不产生学习价值，**淘汰顺序按信息价值排序**而非单纯 LRU。

## 3. 中文思维：语言/学习场景启发

- **温故而知新**：孔子「学而时习之」就是间隔重复的朴素表述——「时习」= 按时间间隔反复。五箱模型把这个「时」量化为 1/2/3/7/15 天的几何级数近似。
- **错题是学习的地图**：「败仗要复盘」——错题本不是收藏夹而是调度队列，每道错题都有明确的「下次见面时间」。遗忘曲线告诉我们：**复习的最佳时机是快要忘记时**，太早浪费、太晚重学。
- **SM-2 到五箱的取舍**：中文语境下的备考节奏（30-90 天冲刺）不需要连续 EF 浮点，五个离散档位足够且用户可理解——「箱」的隐喻直观（错题装箱，答对升箱毕业）。

## 4. 工程实践价值

1. **sha1 签名去重**：同一题（同模块+同题干前 120 字）只入一本——签名哈希把「同一性」判定从全文比对降为 32 字节整数比对，O(1)。
2. **环形容量上限**：错题本无界增长会让 localStorage/progress 文件膨胀——300 条环形 + 价值序淘汰是**有界数据结构**（bounded structure）的教科书应用。
3. **最久未复习优先**：调度策略是贪心的，但在这个问题上贪心=最优（所有未掌握项都必然要复习，顺序只影响边际收益，最旧的遗忘风险最大）。
