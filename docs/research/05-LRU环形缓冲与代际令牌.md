# 05 · LRU、环形缓冲与代际令牌：从「有界记忆」到「缓存与并发治理」

> dsh-kaogong 研究文档 · cycle-19

## 1. 数学/结构定义

**LRU（Least Recently Used）**：利用哈希表 + 双向链表（JS 中 `Map` 的插入序天然可复用）实现 O(1) 的 get/put 与淘汰。命中即重插尾部（`map.delete(k); map.set(k,v)`），容量满则删 Map 首元素（`map.keys().next().value`）——**命中重排 + 满员逐首**，两行代码得到教科书 LRU。

**环形缓冲（Ring Buffer）**：容量 K 的数组 + 写指针，写满覆盖最旧——内存上界恒定，天然防泄漏。数学本质是 `index = (head + i) mod K` 的模运算循环。

**代际令牌（Generation Token / Epoch）**：并发防护模式——每次「取代旧流程」的事件令 `gen++`，长任务每个批次开始前检查 `gen === myGen`，不等即退出。把「竞态条件」转化为「版本号比对」，无锁化。

## 3. 中文思维：语言/学习场景启发

- **温故知新，旧的去处**：记忆容量有限（米勒数字 7±2），大脑用「最近优先」淘汰——LRU 就是对人类记忆淘汰策略的工程仿生。
- **流水不腐，户枢不蠹**：环形缓冲的「覆盖最旧」像日历翻页——去年今天的日程不必留着。lifecycle 日志只留最近 300 条，观测的是「活的状态」不是「死的档案」。
- **一朝天子一朝臣**：代际令牌把「旧流程让位」制度化——新数据根生效的瞬间，所有旧预热批次自动失效退场，不需要显式取消。**让过期者自我识别并退出**，比逐个通知优雅。

## 4. 工程实践价值

1. **Map 即 LRU**：JS `Map` 保证插入序遍历，省掉手写双向链表——标准库即数据结构，零依赖纪律下的最优解。
2. **缓存键的租户维度**：任何响应缓存先列「全部可变输入维度」（ws/root/参数），租户级维度必须进键——v1.8 遥测假阳性与 cycle-17 跨项目污染是同一条纪律的两次实证。
3. **预热与请求的竞态**：长阻塞初始化 + 请求路径兜底是常见模式，代际令牌让「预热让位于请求」无需锁。**先到先得 + 换代即退**，简单且正确。
