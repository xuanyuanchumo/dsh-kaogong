# 22 · SMOKE-IMG-04 间歇假红根治：从概率补捞到确定性配额

> dsh-kaogong 研究文档 · cycle-42 · 目标驱动（根治抽题带图概率性假红）
> 前置：[17-性能研究白盒面板.md](./17-性能研究白盒面板.md)（候选窗口随机采样）· [21-跨源去重治理.md](./21-跨源去重治理.md)
> 状态：**✅ 已实施**

## 1. 症状与取证

SMOKE-IMG-04 断言：池供数抽 10 题应命中至少 1 条 `kgimg://` 带图题。实测 **2/8 轮带图 0**——
间歇假红。取证发现两条**独立的概率漏空链路**：

| 端点 | 原链路 | 漏空机制 |
|---|---|---|
| `/api/questions` → `sampleQuestions` | 候选池 `ORDER BY RANDOM() LIMIT n*3`（18 行）→ richScore 排序 → 补捞条件 `richCount < n/2` | ① 18 行候选在带图占比 15% 时可全无图；② 补捞条件又被「带五维但无图」题（5599 条 / 69%）占满 rich 名额而跳过——两层概率叠加 |
| `/api/pool/questions` | 500 行随机候选 → weightedPick（弱点权重）→ detail 二次查询 | 带图补捞行进 500 池被**稀释**（10/510 期望命中 0.2）——补捞等于没加 |

## 2. 确定性方案（不依赖随机概率）

### 2.1 `/api/questions` · 两级配额

- **L1 带图层**：`stem LIKE '%kgimg://%'` 定向捞 ⌈n/2⌉ 条（池内 1442 条判断推理带图 ≥ 配额必有）
- **L2 五维层**：带五维定向捞补足到 n
- **L3 普通层**：任意行兜底到 n
- 层内 `ORDER BY RANDOM()` 保留多样性；**层间确定性配额**——抽题结果分布可预期

### 2.2 `/api/pool/questions` · 候选补捞 + 结果层配额

- 候选层带图不足 ⌈count/2⌉ → 从带图 id 缓存补入
- 结果层带图不足 → 顺序扫带图池（`imgNeed` 递减必达）——随机起点保留多样性
- **R49 截断语义修正**：带图题稳定分区在前再截 count（否则原 weightedPick 尾部的带图题被切掉，实测 5→4 缺口）

### 2.3 性能护栏

`has_image` 无索引，全表 LIKE 450ms/次会击穿 PERF-04 `<300ms` 基线。
落地 **imgPool 进程级缓存**（has_image=1 的 id+module 列表，一次性全表扫 ~490ms，
与 srcCount 同一失效钩子 `invalidateStatsCache`），后续 O(1) 随机取实测 <1ms。

## 3. 实施期踩坑（R48/R49）

- **R48 · 字段名错配**：`seen` 判重用了 `q.canonicalId`，但 `poolRowToQuestion` 返回对象的
  字段名是 `id`（练习链路契约）→ 全部 `undefined` → seen 把不同题当同一题 → L1 5 条只留 1 条
  （12 轮恒 1）。正解：判重一律用**原始行的 `r.canonical_id`**。
- **R49 · 截断切掉带图**：`questions.unshift` 补足后 `questions.length = count` 保前 count
  → 原 weightedPick 中位于尾部的带图题被切掉（5→4）。正解：**带图稳定分区**（带图在前、
  原相对序不变）再截 count。
- 附带：manifest 新端点缺 `consumers/label` → `/api/graph` 500（R47，cycle-41a 已修）。

## 4. 验证

| 验证 | 结果 |
|---|---|
| 20 轮 `/api/pool/questions` 带图分布 | **全 5**（= 配额下限，零波动） |
| 12 轮 `/api/questions` 带图 | min 5 / max 7，零重复题 |
| smoke 连续 3 轮 | **428/428 ×3** |
| render | **66/66** |
| PERF-04 questions 二查 | <300ms（带图缓存 O(1)） |

**断言升级**：IMG-04 从「带图 > 0（概率性）」升级为「带图 ≥ ⌈10/2⌉=5（确定性配额下限）」——
断言本身成为防回归守卫：任何退回到概率方案的改动都会稳定失败。

## 5. 中文思维

- **「别用抛硬币代替发牌」**：补捞是「再抛一次硬币」，配额是「直接发给你 5 张」——
  概率方案在 15% 命中率下永远有 2/8 的漏空，确定性配额把带图题从「概率事件」变成
  「结构性保证」。
- **「截断不是中性的」**：`length = n` 看着人畜无害，但它按原序切——补足的题在头部
  活下来、原来尾部的带图题被切走。数据流末端的每个操作都要问「它偏好谁」。
