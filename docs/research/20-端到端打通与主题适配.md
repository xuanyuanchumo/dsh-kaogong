## 3. 跨源检索双修（§11.1 达成）

### 3.1 FTS 路径：源多样性轮转（cycle-39 上半）
bm25 让同卷近似题干霸榜（「同比增长」前 10 全 xingce-app）。
修法：每源保底 `ceil(limit/源数)` 条（源内按相关度序），剩余名额按相关度填满。
**透出**：`rotation: 'source-round-robin'|'single-source'` + `sources[]` 命中清单。

### 3.2 LIKE 降级路径：逐源取行（cycle-39 下半）
2 字词（「和谐」）trigram 无法命中 → LIKE 降级，但裸 LIMIT 按 rowid 序被 naoku
占满（30/30），gwy 的 322 条命中在更高 rowid 区间被截断。
修法：逐源 `LIMIT per` 子查询（per = limit×3/源数）。

## 4. 客户端主题适配（第二目标）

### 4.1 取证（沙箱 GUI + emulateMedia）

- 宿主**从不定义** kaogong 用的 `--surface-card/--text-primary` 等变量——全部视图在
  暗色下靠 fallback 白底黑字渲染，**暗色适配从未真正生效**（历史 fallback 是摆设）。
- 宿主真机制：`prefers-color-scheme` + html.style `color-scheme` + `--dsw-alias-*` 令牌
  （暗色实测 bg-layer-1=`#232324`）。

### 4.2 落地（client.tsx 主题适配层）

- **映射层**：宿主 dsw 令牌 → kaogong 五变量（surface-card + 文本四级）
- **亮度守卫（双向）**：暗色拒收暗文本、亮色拒收亮文本（双向实证踩坑：
  暗色下 label-primary-foreground=#0f1115 未跟随；亮色下同令牌=#fff 残值）
- **三通道暗色判据**：computed color-scheme > matchMedia（宿主 JS 强制 vs 系统偏好可能不一致）
- **竞态兜底**：MutationObserver（html style/class 变化）+ 300ms/1200ms 延迟重算
  （宿主样式晚于插件 apply 加载）
- **DOM 守卫**：`HAS_DOM` 探测——render.test（TestRenderer 无 document）安全加载

### 4.3 真机实证（沙箱 GUI）

## 5. 中文思维

- **「最后一里路不走，前面九十九里都白走」**：gwy-zhenti 是最大的题源（8.9 万题），
  却因「paperApi 能用」一直躺在池外——能看不等于能查，**入库才算端到端**。
- **「地毯不能只铺亮色那半间屋」**：fallback 白底黑字让暗色模式成了摆设——
  适配不是「写了 var(--x, #fff)」就算数，**要切到暗色下看一眼**（emulateMedia 实测）。
