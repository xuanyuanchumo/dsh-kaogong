# 04 · Fruchterman-Reingold 力导向布局：从「弹簧网」到「知识地图自动排布」

> dsh-kaogong 研究文档 · cycle-19

## 1. 数学定义

FR 模型把图布局建模为**能量最小化**：节点间同时受两类力作用直到平衡。

- **斥力**（所有节点对，模拟电荷）：`F_rep(u,v) = k²/d(u,v)`，与距离成反比
- **引力**（相邻节点，模拟弹簧）：`F_att(u,v) = d(u,v)²/k`，与距离成正比
- **理想距离**：`k = √(area/V)` —— 布局区域面积除以节点数开根号。这是模型的关键标定：k 随节点数自动缩放，**参数不依赖魔数**。
- 温度模拟：每轮迭代位移上限 `T` 从初始值线性衰减到 0，保证收敛（模拟退火的简化版）。

## 2. 本插件代码落地

| 落点 | 内容 |
|---|---|
| `src/client/graph-physics.ts` | FR 核心：`k=sqrt(area/V)`、度数加权理想边长、离线预收敛 `relax(140)`、流动粒子（`KG_FLOW_RELS` 四类语义边沿线匀速粒子，相位由端点 id 散列——确定性） |
| `src/client/graph-engine.ts` | 引擎装配：Canvas 2D + DPR + ResizeObserver + 指针交互（拖拽钉住 `node.pinned=true`、双击聚焦 1 跳、滚轮缩放、双指捏合） |
| `src/client/graph-transition.ts` | 过渡动画插值 + 视口查询 + 键盘命令纯表 |
| `src/client/graph-canvas.ts` | 画布装配原语：测量/尺寸/光标/小地图绑定 |
| `src/client/graph-view.ts` | 三布局切换（force/layered/circular，`KG_LAYOUTS` 环形轮换）+ 标签去重叠 |

**历史事故（v1.8）**：原 `LINK=90/REP=9000/向心0.004` 魔数在 V≈140 时弹簧与向心压过斥力 → 全图塌缩成中心一团、141 标签 100% 重叠。教训：**力导向参数必须按节点数标定（k=√(area/V)），布局完成后必须 fit() 适配视口**（首帧 wrap 尺寸为 0 时按兜底值算的 fit 会在真实尺寸到达后重算）。

**标签去重叠**：包围盒贪心占位（`labelBoxes`）——按渲染顺序逐个放置标签，与已放置的包围盒碰撞则跳过（画小点）。贪心不保证全局最优，但 O(V·B) 且视觉可接受。

## 3. 中文思维：语言/学习场景启发

- **物以类聚，人以群分**：力导向布局的引力让相关节点聚簇——能力图上「题库域」的节点自动抱团，「方法论域」另一团，社区结构一目了然。标签传播算法（06 篇）把这个视觉直觉变成显式社区标签。
- **疏可走马，密不透风**：书法章法的疏密对比就是斥力/引力的平衡——k=√(area/V) 保证节点平均占位面积恒定，图不会「挤成一锅粥」也不会「散成满天星」。
- **离线预收敛**：`relax(140)` 后停止在线 rAF——就像「下棋前先在心里推演完」，打开图谱即看到稳定布局，省电且不闪烁。**确定性初始化**（id 散列代替 Math.random）保证同数据同布局，用户不会觉得「每次打开图都在动」。

## 4. 工程实践价值

1. **复杂度分层**：朴素 FR 是 O(V²) 每轮；本图 V≈140 在可接受范围，V>600 时走抽样近似（T-026 登记的 octree 缺口）——**先做对的，再做快的，并为快的留登记**。
2. **纯函数外提模式**（cycle-13 ①）：只读纯函数外提到 physics/transition/canvas 三模块，写引擎原语状态的留闭包——复杂度预算 180 的机器守卫。
3. **DPR 感知 + ResizeObserver**：高分屏不模糊、容器变化自适应——布局引擎与渲染管线解耦。
