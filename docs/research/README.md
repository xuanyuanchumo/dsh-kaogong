## 方法论约定（本目录所有文章共同遵守）

1. **五段式**：数学定义 → 本插件代码落地（文件:行号）→ 中文思维/语言场景启发 → 工程实践价值 → 验证方式（可运行的命令）。
2. **只写有落地的**：每个模型必须有仓库内真实代码位置与测试断言支撑——「方便验证与工程实践」是硬门槛。
3. **历史事故即教材**：v1.8 魔数塌缩 / cycle-14 争抢 / cycle-17 跨项目污染等事故在各篇「落地」段如实引用——**失败案例比成功案例更有教学价值**。
4. **语言场景启发服务于功能设计**：每篇的「场景启发」段必须能反推到某个 UI/算法决策，否则删。
