## 3. 用户直报缺陷 → 根因 → 修复

| 用户反馈 | 根因 | 修复 |
|---|---|---|
| **刷题有问题** | 提交后只 `setTick` 重挂载换题，**没有展示对错与解析**——用户点完看不到结果 | 重写视图：提交后**就地**展示「✅正确/❌错误 + 你的答案/正确答案 + 解析 + 错题事件 + 下一题/重答」，并挂模块选择面板与本次统计 |
| **申论有题目没材料** | 练习视图只把题目对象传给前端，从未加载整卷材料 | 选题时并拉 `/api/paper`，新增**给定材料阅读区**（可折叠、分段编号、关联材料提示、缺材料告警） |
| 筛选功能不够 | 真题卷仅科目+年份 | 保留并补：模块选择/模式切换/题型筛选（申论五类）/知识点检索 |
| 仪表盘/图谱/可观测简陋 | 数据维度单一 | 仪表盘加**资源总览**（题库规模/申论战绩/模考战绩/错题）；图谱/可观测丰富化为 T-020 |
| 要可选模型评估 | 无模型入口 | 新增 `kaogong_ai_essay_review` 工具：先取离线基线分与方法论，再交模型深度点评（无模型时离线评分照常可用） |

## 4. 三项技术债闭环

### T-018 题目配图（11 万张本地图）
- `/api/paper-img?id=&p=` 二进制服务：`dirname(paperId)` 为基准目录 + 路径穿越防护 + 扩展名白名单 + 流式响应
- markdown 图引用改写为端点 URL，`RichText` 组件渲染 `<img>`（`loading=lazy`，失败隐藏）
- **实测**：200 / image/png / 28651 bytes；行测卷 9 题含图全部可加载

### T-016 整卷模考
- `exam/start` 返回整卷**不含答案**（防作弊）；`exam/submit` 服务端比对计分
- 前端：倒计时（行测 120min）+ 逐题作答 + 交卷 → **模块得分分布（弱→强排序）+ 错题清单**
- **实测**：用真实答案交卷 140/140 = 100%，模块分布按题型细分正确

### T-017 大作文分档
- 字数五档（严重不足/偏少/合格/略超/明显超标）+ 结构要素（开头/分论点/结尾）+ 论证标志密度 + 语言
- **实测**：结构完整范文 28.6/40 vs 口语敷衍 6.1/40；识别出 3 个分论点、2 个论证标志
