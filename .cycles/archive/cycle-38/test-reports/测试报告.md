（`study-view` 已消费 `q.dims`），练习卡直接渲染「解题思路/最快解法/易错陷阱/母题思维」。

### 3.2 学习事件双写（缺口 ③ · 研究 15 C7 显式口径）

```
判对 → study_event(action='answer',  is_correct=1)
判错 → study_event(action='collected', is_correct=0, box=1)   ← 错题本事件同步沉淀
白盒 → /api/pool/status.studyEvents = { total, byAction, topKadian(带正确率) }
```

**双写期语义显式**（S2-05 守卫固化）：progress json 仍是统计/错题本权威事实源（读路径零改动）；
study_event 只沉淀流水（阶段 3「按 kadian 诊断」的原料）。写失败静默，判分主链路零影响。

### 3.3 rich 优选（缺口 ② 部分交付）
