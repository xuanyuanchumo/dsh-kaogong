# cycle-29 循环总规划（v1.26.0）

## 本轮目标（源自用户直接请求）

以 dsh-anic L4 全自主模式驱动自举循环迭代，核心四件事：
1. **P0 命令窗口显示问题根治**：6 个 AI 工具接入宿主 `presentCall`/`presentResult` UI 展示契约
2. **P1 图谱可视化增强**：消费已声明未消费的 neighborhood/impact 端点，实现子图按需加载 + 影响面量化
3. **可观测性补强**：子图面包屑、口径提示、面包屑量化（节点/边计数）
4. **质量闭环**：守卫断言 8 条（C29-01..08）+ render 旅程断言 + 三锚点版本同步 v1.26.0

## 根因分析（调研取证）

- **命令窗口问题**：宿主 asar 二进制扫描证实 presentCall 引用 148 处、terminal 卡片 16 处 → 宿主完整支持展示契约；本插件 6 工具均未声明 → 宿主回退 generic 兜底（title=工具名、raw args 平铺），用户感知为生硬「命令窗口」。契约来自 dsh-plugin-dev-kb `site/reference/subsystems/tools.md` L90-107 + L624-629。
- **图谱缺口**：`/api/graph/neighborhood`（k跳邻域）与 `/api/graph/impact`（反向可达）端点在 manifest 已声明（L120-124）、server 已实现（http.ts graphQuery），但 UI 零消费——「按需加载」缺口实证。
