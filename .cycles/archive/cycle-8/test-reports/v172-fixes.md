## 3. 用户直报缺陷 → 根因 → 修复

### 3.1 刷题图片题图片缺失

| 环节 | 问题 |
|---|---|
| 数据层 | naoku 题目的 `img_refs` 字段**从未转成 markdown**，题干里根本没有图 |
| 路径 | DB 记录 `/90-图片/题目图/xxx.webp`，但磁盘只有 `.png`（39051 个 png，0 个 webp） |
| 服务 | 没有图片服务端点 |

**修复**：新建 `adapters/naokuImage.js`
- `resolveNaokuImage()`：按「去扩展名 basename」在 `.png/.jpg/.webp/...` 中探测，并以前缀匹配兜底
- `safeImagePath()`：路径穿越防护 + 扩展名白名单
- `imageMarkdown()`：生成 `![](/kaogong/api/naoku-img?p=...)`
- `naokuQuestions()` 注入图片 markdown；新增 `/api/naoku-img` 二进制端点

**验证**：API 层图片 200 / image/png / 23244–31692 bytes；真机抽题 5 张图**全部 `naturalWidth > 0`**。

### 3.2 专题结构（行测/申论未分离、申论练习孤立、缺行测练习）

**修复**：新建 `server/topicTree.js` + 重写 `NativeTopicsView`

| 频道 | 专题数 | 练习入口 |
|---|---|---|
| 行测 | 17（6 模块 + 11 细分题型） | 刷题(SRS) / 深度题库 / 整卷模考 / 真题卷库 |
| 申论 | 5（概括/分析/对策/应用文/大作文） | 申论练习 / 真题卷库 |

每个专题带 `entry: {view, params}` 统一路由；UI `onGo(view, params)` 切视图并传参。

**验证（真机）**：
- 频道切换：`data-kg-channel` 定位，切到申论显示 5 个题型专题 ✅
- 申论跳转：点「申论 · 概括」→ 申论视图 + 题型筛选自动应用 ✅
- 行测跳转：点「判断推理」→ 刷题视图 + **自动抽题**（不停在模块选择页）✅
