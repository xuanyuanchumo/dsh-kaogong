## 主题：TS+React 统一视图模板重构（v1.18.0）

### 核心命题：统一模板 =「useKgData 数据hook + ViewShell 视图骨架」

现状实证：10 个视图各自手写 fetch/loading/error 三态（study-view 45 处 hook 调用、obs-view 1101 行），四态语义（loading/error/empty/data）漂移、重试/abort 各写各的。重构不是引入新 React 实例（combo factory 单作用域唯一 `require('react')` 铁律），而是：

1. **tsconfig 启用 JSX**：`"jsx": "react", "jsxFactory": "h"`——视图升级为 .tsx 组件文件，编译产物仍是 `h(...)` 调用（bundler/宿主契约零变化，require('react') 仍只在 ui-kit.ts 发生一次）。
2. **`client/view-kit.tsx` 统一模板**：
   - `useKgData(url, opts)` 数据 hook：四态状态机（idle/loading/error/empty/ready）+ AbortController 竞态防护 + 手动重试 + 失败快照保留（err 时不丢上次数据）
   - `ViewShell` 骨架：标题栏/工具栏/内容区 + 四态渲染（骨架屏 loading / 错误重试卡 / 空态引导 / 数据 children）+ 响应式断点类名
   - `Toolbar`/`SectionCard` 组件（样式 token 化）
3. **试点迁移**（全部 10 视图分轮推进，本轮 2 个最高价值）：`obs-view.tsx`（管理面板，用户重点）+ `repos-view.tsx`（题库管理面板）；其余视图本轮仅保证兼容，后续循环迁移。
