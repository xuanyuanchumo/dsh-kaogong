# cycle-27 当前循环总规划（v1.23.0）— 模考四区划分 + 真题卷整卷模式

## 用户诉求

> 模考区域划分优化为：材料区（没有就隐藏）→ 题目区（一个材料多个题目）→ 题目切换区（上一题/下一题）→ 答题卡区。真题卷也采用整卷模式（整卷由单题组合成），继续组件化。

## 现状盘点

- exam（模考做题态）：单卡渲染 QwQuestionCard（无组材料——start 端点 map 剥离了 type/groupMaterial）+ 答题卡在上 + 上下题在下，四区无空间语义
- papers（真题卷浏览）：材料区（卷级）+ 130 题垂直长列表——无题间导航、无「整卷由单题组成」的结构感
- 实测：模考 start 下发 130 题，0 题带组材料（防作弊剥离时把组材料一起剥了——组材料不是答案，必须保留）

## 目标架构（组件域扩展，零新轮子）

### question-kit 新增/扩展

1. **`QwPaperMode`（整卷容器）**：props `{ questions, answers?, flags?, current, onJump, onSelect?, mode: 'exam'|'browse', paperMeta }` ——
   - **区1 材料区**：当前题的 groupMaterial（QwMaterial 自治折叠；无则整区隐藏 ✔用户诉求）
   - **区2 题目区**：QwQuestionCard（当前题，material 段禁用——材料已在区1，避免双事实源）
   - **区3 题目切换区**：上一题/下一题/位置指示（`idx+1 / N`）
   - **区4 答题卡区**：QwExamNavigator（exam 态带交互四态；browse 态只读跳转）
2. **start 端点补字段**：`type` + `groupMaterial`（rewriteImages 处理）——组材料非答案，保留不违防作弊

### 视图接入

- exam 做题态：分支渲染改为一行 `<QwPaperMode mode="exam" ...>`（四区顺序内置）
- papers 详情：整卷浏览改 `<QwPaperMode mode="browse" ...>`（材料区跟随当前题组自动切换 + 只读答题卡跳转）——替代 130 题垂直长列表

### 共享行为

- 题组感知：材料区显示「材料 N · 共 X 题用此材料」；同组题切换时材料区不重挂（key=材料号）
- 响应式：窄屏四区纵向堆叠（默认），宽屏材料区+题目区同行、答题卡右侧栏（≥1100px 复用 graph-view 的 wide 断点口径）
