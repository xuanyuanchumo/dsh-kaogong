## 5. 架构决策（本循环新增）

- **AD-13.1 模块拆分模型（T-022 扩展）**：`src/client/client.ts` 拆为
  `client.ts`(entry/combo 头/通道/挂载) + `ui-kit.ts`(无状态组件/样式) + `graph-engine.ts`(Canvas FR 物理) +
  `graph-view.ts` + `obs-view.ts` + `study-view.ts`(仪表盘/刷题/错题本/计划/检索/方法论) +
  `papers-view.ts`(真题卷/专题/申论/模考/深度题库/图形推理)。
  tsc 多文件编译 → `scripts/bundle-client.mjs`（零依赖，拓扑排序）把 dist/client/*.js 合并为**单个 combo factory**
  （微模块注册表 `__kgDefine/__kgRequire`）。
  硬约束：产物必须保住 smoke 全部静态守卫的**文字形态**
  （`h(NativeGraphView, { key: 'g' + tick, data: data.g`、combo 头、`return {inject:…], apply(ctx)`、ErrorBoundary 类名）。
- **AD-13.2 索引 v2（省份）**：`.paper-index.json` 增加 `schemaVersion:2` + `province`
  （`省考/<省份>/...` 取 parts[1]；国考 → 全国；特殊招录类 → 目录名）+ `provinces` facet
  （名称/卷数/年份跨度/科目分布，排序确定性）。旧快照自动失效重建。
- **AD-13.3 流动可视化**：注册（manifest 声明）→ 生产（server 实现）→ 消费（client/UI 调用）
  三列 SVG 流动图，数据源 `/api/capabilities` + 遥测；零依赖手绘，字段缺失降级为列表。
- **AD-13.4 复杂度不调预算**：预算保持 180，靠真实拆分达标（R06 不降级 / R07 不条件通过）。
- **AD-13.5 专题枢纽（用户反馈 2026-11-03）**：主导航精简为
  仪表盘 / 专题 / 真题卷（省份） / 错题本 / 图谱 / 可观测；
  刷题、深度题库、图形推理、申论四视图**收纳进「专题」页内分区 tab**（保持组件与端点不变，只改导航与专题页容器）；
  专题页新增「方法论技巧」分区（kaogong-skill 10 主题方法论 + naoku 母题思维/易错点精选聚合）。
- **AD-13.6 对话窗口瘦身（用户反馈 2026-11-03）**：右侧 tab（KaogongTabBody）不再内嵌练题流程，
  改为引导卡 + 学习摘要 + 快捷入口（打开左栏面板 / 浏览器标签）；全功能收敛到左栏原生面板。
