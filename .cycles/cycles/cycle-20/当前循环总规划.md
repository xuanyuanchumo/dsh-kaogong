## 2. 缺口 → 落地映射（按用户价值排序）

| ID | 缺口 | 落地 | 验证 |
|---|---|---|---|
| G1 | **clone 失败残留半成品 → 死锁**（clone 中途失败留下无 .git 目录，下次 install 判「非 git 目录拒绝覆盖」，用户无法自恢复） | `startJob` 失败时自动清理本次 clone 产生的目录（仅当本次创建、且无 .git）；`install` 对「无 .git 的空目录/空壳」允许安全重建 | SMOKE-RM-01/02 运行时 + 静态守卫 |
| G2 | **「一键必选」名不副实**：逐个按钮 + 并发上限 2 → 第 3 个被拒 | 新增 `/api/repos/install-batch` 批处理端点：队列化（串行/并发≤2），返回 batchId + 逐项结果；UI 一个「🚀 一键安装全部必选」按钮 + 批次进度条 | SMOKE-RM-03（端点契约）+ C21 render（批次按钮/进度） |
| G3 | **作业无历史**：Map<key,job> 完成即被覆盖，失败原因/日志丢失 | 作业归档：`jobHistory` 环形 20 条（key/action/state/error/耗时），`/api/repos/jobs` 端点；UI 「最近作业」区（可展开历史） | SMOKE-RM-04 |
| G4 | **换根无提示**：切根后已装仓库「消失」 | `/api/repos` 增 `previousRoot` + `previousRootRepos`（旧根下仍存在的仓库数）；config 切换时记录旧根快照；UI 明示「旧根仍有 N 个仓库」+ 一键切回 | SMOKE-RM-05 + C21 render |
| G5 | **config 无校验**：root/mirror 任意写、无写权限探测 | root 绝对路径校验 + 可写探测（mkdir/写探针）；mirror 仅允许 http(s) 前缀；非法返回 {error} 不落盘 | SMOKE-RM-06 |
| G6 | **无健康巡检**：已装仓库 .git 丢失/陈旧不可见 | `repoState` 增 `health`（ok/no-git/empty/stale）+ `lastCommitAt`（.git/HEAD 或 FETCH_HEAD mtime）；`/api/repos` 汇总 healthSummary | SMOKE-RM-07 |
| G7 | **浏览截断口径不一致**：服务端 300 / UI 120 / 文案「前 120 项（共 X）」 | 统一：服务端返回真实 total，UI 按服务端 `items.length` 渲染、文案由 `truncated` 决定；补 `limit` 参数 | SMOKE-RM-08 |
| G8 | **安装前无空间/可达性预检** | `install` 前：目标根可写探测 + 上游 URL 形状校验；`statusSnapshot` 增 `diskFreeMB`（statfs 可用）；UI 必选卡显示可用空间 | SMOKE-RM-09 |
