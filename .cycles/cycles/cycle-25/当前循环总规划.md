# cycle-25 当前循环总规划（v1.20.0）— 统一题目渲染域（单题/整卷一套数据结构）

## 用户诉求

> 单题渲染逻辑用同一套：0.编号 1.来源 2.类型 3.材料 4.问题 5.选项 6.答案解析；3-6 可能含图，前端需支持折叠/展开/放大缩小。整卷渲染同一套但前端逻辑不同（做题模式 1-6 显示变化 + 题目跳转组件）。借鉴主流刷题软件完善。

## 现状盘点（6 处独立渲染实现 = 漂移温床）

| 渲染点 | 形态 | 缺口 |
|---|---|---|
| practice（刷题） | SourceBadge+RichText+OptionRow+解析 | 无编号/类型段；图片不可放大 |
| deepbank（深度题库） | 自建 dims 五维块+材料块 | 与 practice 口径不同（材料/来源顺序不同） |
| tuxing（图形推理） | 自建选项图分支 | 无五维/材料 |
| papers（真题卷详情） | 整卷只读+材料折叠+jumpToMaterial | 与单题链路零复用 |
| exam（模考） | 自建选项行（chosen 态）+ 上下题 | 无答题卡跳转（只能线性翻页）；无来源/类型 |
| essay（申论） | 材料折叠+作文题干 | 无编号徽章体系 |

## 目标架构：`src/client/question/` 组件域（Qw* 前缀，bundler 子目录）

```
src/client/question/
├── question-kit.tsx        # QwQuestionCard（0-6 组装器）+ 分段组件 + QwExamNavigator（答题卡）
│   ├── QwNumberBadge       # 0 编号（圆徽章 + 分值 + 标记旗）
│   ├── QwSourceMeta        # 1 来源（复用 KG_SOURCE_META：题库·真题/深度题库/图形推理/真题卷）
│   ├── QwTypeTag           # 2 类型（模块/题型/专题 chip）
│   ├── QwMaterial          # 3 材料（受控折叠：collapsed/onToggle 由宿主持有——保 smoke 1534 契约）
│   ├── QwStem              # 4 题干（RichText + 图可点击放大）
│   ├── QwOptions           # 5 选项（interactive: 答题态 chosen/right/wrong / readonly: 浏览态）
│   ├── QwAnswerDims        # 6 答案解析（五维标注 DimBlock 统一 + 参考答案折叠）
│   └── QwExamNavigator     # 整卷做题模式答题卡：网格跳转 + 已答/标记/当前三态 + 计数
└── question-lightbox.tsx   # QwZoomImg（图片点击放大）+ QwLightbox（全屏遮罩：滚轮缩放/拖拽/ESC）
```

## 数据契约：QwQuestion（规范化输入，七段齐备）

```ts
interface QwQuestion {
  no?: any                    // 0 编号
  source?: string             // 1 题库来源键（KG_SOURCE_META）
  exam?: string; year?: any; region?: string; paperFile?: string  // 1 卷源
  type?: string; module?: string                   // 2 题型/模块
  material?: string; materialRef?: string          // 3 材料
  stem?: string               // 4 题干
  options?: Record<string, string>                 // 5 选项
  answer?: string; analysis?: string               // 6 答案/解析
  dims?: { analysis?, kadian?, reasoning?, fastest?, pitfalls?, mother? }  // 6 五维标注
  score?: number; requirement?: string             // 申论附加
}
```

**接入纪律**：各视图把既有数据对象 map 成 QwQuestion（一行适配，零 server 改动）；七段按「有则渲染」——不臆造空段。

## 交互设计（借鉴粉笔/华图）

- 单题模式：0-6 全显示；材料默认展开（>500 字折叠）；解析答对后自动展开
- 做题模式（整卷）：1 来源恒显；材料窄屏折叠/宽屏常驻；**答题卡跳转**（网格 + 未答灰/已答蓝/标记黄/当前描边）+ 标记本题旗 + 已答计数
- 图片：题干/材料/选项/解析内 `<img>` 全部可点击 → QwLightbox（滚轮缩放 0.5-4x、拖拽平移、ESC/点遮罩关闭）；material/stem maxHeight 折叠已有，保留
- 键盘：←→ 切题（做题模式），ESC 关 lightbox

## 约束（全部有事故背书）

1. Qw* 前缀顶层名唯一（⑨ combo 单作用域）
2. question/ 组件零模块级可变状态（R7）；lightbox 状态组件内 useState
3. hooks 恒定：早退 return 在全部 hooks 之后（C24-2）；派生防御读取（C24-3）
4. QwMaterial 受控（collapsed/onToggle props）——smoke 1530/1534 锚定 collapsedMats/toggleMat/jumpToMaterial 在 papers-view 源码内，状态留宿主
5. 客户端中文注释全保留；不压缩不重命名
6. 并行纪律：subagent 只跑 tsc --noEmit；build/test 收口独占（③）
7. smoke/render 形态锚点同波次更新（C24-4）
