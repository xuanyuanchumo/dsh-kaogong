## 技术约束（改动前必读，全部有历史事故背书）

1. **bundler 子目录支持（W1 基建，先行）**：`bundle-client.mjs` 的 importRe
   `[\w-]+` 不匹配 `/` → 升级为 `[\w/-]+`；模块发现递归扫子目录；模块 id
   `client/views/graph-view`。拓扑序/重名防御/原子写逻辑不变。
2. **tsconfig**：`include` 加 `src/**/*.tsx`；`jsx: "react"`（classic runtime，
   产出 `React.createElement`，与 factory 内 `require('react')` 闭包可见匹配）。
   **禁止 jsx: "react-jsx"**（会产出 `import { jsx } from 'react/jsx-runtime'`
   → 行首 import → R11 复发）。
3. **React 引入形态**：所有 .tsx 文件用 `const React = require('react')`，
   **禁止 `import React from 'react'`**（verbatimModuleSyntax 保留该语句 → 产物
   行首 import → assert-combo 响亮失败）。
4. **顶层名全局唯一**：单 combo 单作用域，模块前缀纪律不变
   （graph 系 graph*/KG_*、study 系 kg*/Kg*、obs 系 Obs*/sup*）。
5. **注释与产物纪律**：中文注释全保留；不压缩；不重命名标识符；
   `import type` 擦除形态不变。
6. **并行纪律**：多工人并行只允许 `npx tsc --noEmit`（只读）；build/smoke/render
   收口独占跑（教训③）。
7. **测试路径同波次**：smoke/render 的 readSrc 硬编码路径与新目录同步（教训：
   改位置必须同波次 grep 全部引用点）。
