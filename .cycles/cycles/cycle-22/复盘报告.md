## 教训编码化（本轮新增候选）

1. **「同族链路修复必须全字段枚举」**：cycle-21 修复了 parseQuestions（练习链路）与题干 img_refs（深度题库），但**同一适配器内**的 options/analysis/reasoning/fastest/pitfalls/mother 六个字段仍在走旧的 stripHtml——修复面按「链路」划分而非按「字段」划分，导致同文件内半修复态。规矩：修「剥 HTML」类缺陷时，先 grep 该文件全部 `.replace(/<[^>]+>/g` 调用点，逐一判定业务语义，不留幸存者。
2. **端点「实现+消费」齐备 ≠ 已声明**：/api/kg-img 服务端实现、RichText 消费都在 v1.16.0 上线，但 manifest 漏登记 → 能力对账面板与 smoke 口径守卫看不到它。规矩：新增端点四步纪律（manifest → server → UI → smoke）的第四步之前加一步「manifest 声明核对」，端点清单以 manifest 为唯一事实源。
